Section 2 – Probability of each token → perplexity

The probability of each token is evaluated using the model's logits at the step immediately before it.

# Token Probability P 1 / P
Step 1 Multiply all the 1/P values
Step 2 Number of tokens (N)
Step 3 Perplexity = (product)1/N
Computed stably using log-space: exp( average of −ln P ). Lower perplexity means the model found the text more predictable and natural!
